# Image Processing Studio

This Streamlit app is a presentable GUI project for the image-processing requirements shown in the assignment screenshot.

## Run

From the project folder:

```powershell
python -m streamlit run app.py
```

## Included Operations

- Original image comparison
- Grayscale conversion
- Negative image
- Binary thresholding
- Brightness and contrast adjustment
- Gamma correction
- Gaussian blur
- Sharpening
- Sobel edge detection
- Emboss filter
- Histogram equalization
- Sepia transform
- K-means color quantization
- Binary morphology: dilation, erosion, opening, closing
- RGB channel viewer

## Presentation Features

- Upload custom images or use a generated sample image
- Adjustable controls for processing parameters
- Original vs. processed preview
- RGB histogram comparison
- Algorithm explanation tab
- Processed PNG download button

## Bonus Work

The app includes additional algorithms beyond the basic lab set: histogram equalization, K-means color quantization, morphology, Sobel edge detection, and gamma correction.
